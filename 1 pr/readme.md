Название проекта **Инструмент для сохранения веб-страниц для чтения позже "HoldIt"**

УТП Сохраняйте всё важное из интернета и возвращайтесь к этому без отвлечений — даже без интернета. Приложение превращает статьи, посты и документы в удобную персональную библиотеку: очищает их от рекламы, синхронизирует между устройствами, позволяет выделять главное и помогает быстро находить нужную информацию.
